==============================================================================
  ANALYSIS
==============================================================================

  cpu-z80 v0.2 is approximately 2.8x faster than z80ex.

  Main sources of speedup:
  1. Computed goto dispatch vs function pointer dispatch
  2. Batch execution z80_execute() vs per-step z80ex_step()
  3. Local register cache (registers in C locals, not in struct)
  4. Inline prefix handlers (no function calls for CB/ED/DD/FD)
  5. Local callback pointer cache in z80_execute()

  Note: z80ex has no batch execute, so each instruction requires
  z80ex_step() call -> function pointer dispatch -> return. cpu-z80
  uses z80_execute() with internal computed goto, eliminating
  function call overhead per opcode.

==============================================================================
  VERSION HISTORY - PERFORMANCE IMPACT
==============================================================================

  The figures above were measured on cpu-z80 v0.2. The v0.2.x patch
  releases that follow only add new event callbacks - they default to
  NULL and the dispatch loop takes a single NULL pointer check per
  affected opcode. No measurable regression was observed beyond run-
  to-run noise (~3 % on this benchmark host).

  Releases since v0.2:

  v0.2.1   op_tstate tracking, M1_FETCH distinction, Q register,
           EI callback. Cycle count unchanged.
  v0.2.2   Bugfix: lost register writes from callbacks during
           instruction (-0.2..-0.5 %, within noise).
  v0.2.3   Added di/im/halt/nmi event callbacks (NULL by default).
  v0.2.4   Added unified iff_change callback (NULL by default).
  v0.2.5   Added cpu_ctrl_event callback for HALT/RST observers
           (NULL by default).

  Comparative measurement, same host, same session (5 runs each):
    v0.2.1 + bugfix (no new callbacks):  O2 2846 MHz, O3 2861 MHz
    v0.2.5 (all callbacks present):      O2 2857 MHz, O3 2845 MHz

  Difference is +0.4 % on O2, -0.6 % on O3 - both within the ~30 MHz
  run-to-run spread on this benchmark. The 2.8x speedup vs z80ex
  holds across all v0.2.x releases.
