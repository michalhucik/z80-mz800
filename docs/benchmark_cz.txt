==============================================================================
  ANALYZA
==============================================================================

  cpu-z80 v0.2 je priblizne 2.8x rychlejsi nez z80ex.

  Hlavni zdroje zrychleni:
  1. Computed goto dispatch vs function pointer dispatch
  2. Batch execution z80_execute() vs per-step z80ex_step()
  3. Lokalni registrova cache (registry v C promennych, ne ve strukture)
  4. Inline prefix handlery (zadne volani funkci pro CB/ED/DD/FD)
  5. Lokalni cache callback pointeru v z80_execute()

  Poznamka: z80ex nema batch execute, proto kazda instrukce vyzaduje
  volani z80ex_step() -> function pointer dispatch -> navrat. cpu-z80
  pouziva z80_execute() s internim computed goto, coz eliminuje
  overhead volani funkce na kazdy opcode.

==============================================================================
  HISTORIE VERZI - DOPAD NA VYKON
==============================================================================

  Hodnoty vyse byly merene na cpu-z80 v0.2. Naslednujici patch verze
  v0.2.x pouze pridavaji nove event callbacky - ve vychozim stavu jsou
  NULL a dispatch smycka pridava jeden NULL ptr check na dotcenem
  opkodu. Zadna meritelna regrese mimo run-to-run sum (~3 % na tomto
  benchmark hostu) nebyla pozorovana.

  Vydani od v0.2:

  v0.2.1   op_tstate tracking, M1_FETCH rozliseni, Q registr, EI
           callback. Pocet cyklu nezmenen.
  v0.2.2   Bugfix: ztracene zapisy registru z callbacku za behu
           instrukce (-0.2..-0.5 %, v ramci sumu).
  v0.2.3   Pridany di/im/halt/nmi event callbacky (NULL by default).
  v0.2.4   Pridan sjednoceny iff_change callback (NULL by default).
  v0.2.5   Pridan cpu_ctrl_event callback pro HALT/RST observery
           (NULL by default).
  v0.2.6   Pridany call / ret dispatch hooky pro callstack subsystemy
           (NULL by default).
  v0.2.7   PC drzi adresu instrukce HALT behem HALT (realne Z80
           chovani; jen op_76 + INT/NMI accept).

  Srovnavaci mereni, stejny host, stejna session:
    v0.2.1 + bugfix (bez novych callbacku): O2 2846 MHz, O3 2861 MHz
    v0.2.5 (cpu_ctrl_event pritomny):       O2 2857 MHz, O3 2845 MHz
    v0.2.6 (i call/ret pritomne):           O2 2893 MHz, O3 2912 MHz
    v0.2.6 vs v0.2.7 A/B (jina session):    O2 ~2790 / ~2790 MHz oba

  Rozdily se vejdou do rozptylu mezi behy / session na tomto benchmark
  hostu (A/B v0.2.6-vs-v0.2.7 bezel v jine session, proto nizsi
  absolutni cisla - obe verze se shoduji). 2.8x zrychleni vuci z80ex
  plati pro vsechna v0.2.x vydani.
